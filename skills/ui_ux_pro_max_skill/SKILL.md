# UI/UX Pro Max + 21st.dev Design Intelligence Skill

## Core Pre-Delivery Checklist (Enforced)
1. **Zero Raw Emojis as Icons**: All interface icons MUST use crisp inline Lucide/Heroicon SVGs (`stroke-width="1.75"` or `1.85`).
2. **Dense Operations Dashboard Scale (`--density 8 --motion 3`)**: Uses disciplined 4px/8px/12px spacing tokens (`--space-1` to `--space-6`), tabular numerals (`font-variant-numeric: tabular-nums`), and zero text clipping.
3. **21st.dev Magic Component Primitives**:
   - Spotlight radial hover cards (`--mouse-x`, `--mouse-y` CSS glow)
   - Animated SVG ring gauges with `stroke-dashoffset` spring transitions
   - Glassmorphic chamfered HUD windows with corner precision reticles
   - Accessible native `<button>` semantics, visible `:focus-visible` rings, and `prefers-reduced-motion` support
